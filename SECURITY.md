# Security Policy

Ward is an early stage project and is not intended to be a hardened sandbox for
untrusted code.

## Reporting a Vulnerability

Please avoid filing public issues for security-sensitive findings.

Preferred reporting channel:

1. Use GitHub's "Report a vulnerability" (Security Advisories) for this repository.
2. Otherwise, open a GitHub issue with minimal detail and request a private follow-up.

When reporting, please include affected version(s), impact, reproduction steps,
and any mitigation ideas.

## Supported Versions

Security fixes are provided for the latest released version only.
